# GPUI 设计与交互回归

本轮核对当前已经接入 Document Service 的 UI，修复实际交互问题并提供可重跑的原生窗口
验收。它不表示 [完整交付矩阵](../designs/source-daw/06-delivery.md) 的 P4/P5 已经全部完成。
基于现有未提交工作区继续实现，没有改写音乐工程、依赖包或音频回调。

## 修复

- 未保存工程原生关闭与 ⌘Q 经过确认；Save & close 关联自身请求与同一 session/revision 的
  已保存 View。失败、新编辑或服务重启取消自动关闭；Cancel 不撤销在途 Save。
- 帮助/关闭弹层在根捕获阶段隔离快捷键，遮挡底层鼠标命中并取消活动手势，防止焦点仍在
  钢琴或插件时触发 Delete、Undo、播放、F9 或关闭内部窗口。
- 源码诊断独立于 native 图诊断，迟到的图 Accepted 不擦除当前源码错误；状态栏区分
  错误代码、冲突、断线、保存、同步及图更新。Code/CreateFile 可修复 invalid 草稿。
- 插件详情明确显示 Initial settings；Edit configuration 导航到准确的使用位置，默认 This use。
  配置表单置于使用列表之前，切换后回到顶部；窄窗口的插件管理操作可换行。
- Add package 的 Enter 路径使用操作就绪判定，invalid 工程也可以提交缺失包安装。
- 钢琴窗切换独占后，原分隔线沿用小面板的坐标和上限，实测向上拖 30 px 只增加 4 px。
  新分隔线在 prepaint 使用本帧尺寸生成绘制位置、命中区域与拖动上限。回归同时核对
  边界对齐、真实命中与跨区域拖动，未放宽原来的位移断言。
- 外部面板旧故障注入试图保留 instanceId 更换插件身份，被当前 authoring 规则提前拒绝，
  无法抵达预期的 native 拒绝阶段。fixture 改为创建独立缺失插件 Channel，保持原有自动化；
  语法、运行时、native、布局回退和恢复阶段仍分别核对。
- 导航冒烟按当前默认布局初始化：用实际 + 按键放大到出现横向溢出，再验证滚动；
  用 F9 打开默认隐藏的 Mixer 再验证选择导航，不向不可见编辑器强塞焦点。

窗口组合、关闭状态、原生关闭交互、配置导航、使用列表及力度分隔线按职责拆分。
手写模块保持约 300 行以内；音乐编辑仍通过 Node 语义事务，没有新增 source ID 或 DSP setter。

## 尚不能宣称完成的范围

- 插件详情的旋钮仍是初始配置呈现，连续参数试听/effective telemetry、typed runtime
  setter、ABI 2 和原生 companion 尚未完成。配置表单可回写 TS，但不等同于这些能力。
- 当前插件详情按 owner/slot 寻址，重排后跟随该槽位；音频 automation 使用实例绑定。
  详情窗口跟随同一实例的迁移仍需后续实现。
- Clip 裁切/拆分、完整 Sample 编辑，以及交付矩阵中的高级结构编辑仍有缺口。
- NSEvents 和 GPUI 键盘分发不是物理设备验收；IME、VoiceOver、Tab 焦点完整性、原生交通灯
  与全屏/运行中系统外观切换仍需专门验收。进程强杀也不经过本轮的关闭确认。
- 本轮小工程截图与算法基准不证明十万事件工程的整窗性能，也不替代真实设备 endurance。
