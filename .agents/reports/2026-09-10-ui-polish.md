# UI polish: semantic automation and plugin modules

Automation lane labels now resolve through accepted channel, bus, insert and plugin instance data.
The editor uses a destination row followed by parameter buttons; Browser entries show parameter first
with a quieter owner line. Channel `level` is Volume, host mix is Dry / wet, sends name their target,
and duplicate instances retain distinct keys without exposing source IDs.

Bundled plugin panels use bordered module surfaces with a title strip. Choice controls sit in compact
horizontal selectors while knobs keep equal columns. Wavetable is split into Oscillators, Filter & output,
Modulation and Matrix pages. Window titles and configuration actions use the plugin-first hierarchy.

Validation: Preview tests 69 passed; workspace Rust tests 546 passed, 0 failed, 3 ignored; release layout
benchmark p95 174.667 µs / p99 225.125 µs for 256 controls; all 30 bundled panels, light/dark narrow
captures, Wavetable page captures, edit/save/reopen, automation edit and third-party watch recovery passed.
No system audio output was opened.
