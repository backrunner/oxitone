# Compact view menu — 2026-10-05

- Replaced the titlebar's separate editor tabs and auxiliary view buttons with one Views icon
  and dropdown. Arrange, Piano and Mixer precede Automation, Plugins and Browser; the current
  view is checked. Keyboard help remains a separate icon.
- Reused the existing internal-window behavior and F5/F7/F9 shortcuts. Opening the menu cancels
  active gestures; menu keys and outside clicks cannot edit notes, seek, start playback or
  bring an underlying internal window forward. Escape, Tab and a second trigger click dismiss it.
- Native pointer and keyboard smoke passed at 1440 × 920 dark and 1060 × 720 light. It opens all
  six views, revisits Piano, checks keyboard isolation and dismissal, and preserves the document
  revision. Both screenshots were inspected. The DAW fixture also saves and reopens its source.
  All audio uses the simulated sink; no system audio device is opened.
- Formatting, lint, TypeScript checking, Rust formatting and workspace tests passed:
  663 Rust tests passed, 3 benchmark tests ignored. The release UI editing benchmark passed
  separately on Apple M5 Max, macOS 27.0.0 (100 warmups, 1,000 samples per scenario).
  The largest measured p95/p99 was 883.375/924.125 µs for restoring a 10,000-note selection.
  This existing benchmark measures editing algorithms, not dropdown rendering, GPU frames
  or audio callback latency. The change adds no audio callback work.

Reproduce the native checks with `scripts/build-preview.mjs --debug`, then run
`scripts/smoke-daw.mjs` with `OXITONE_PREVIEW_CAPTURE_VIEW_MENU=1`, the desired
`OXITONE_PREVIEW_CAPTURE_SIZE` / `OXITONE_PREVIEW_APPEARANCE`, and
`OXITONE_PREVIEW_CAPTURE_OUTPUT`. Both scenarios are included in `scripts/smoke-ui.mjs`.
Screenshots and logs: `target/views-dark.png` and `target/views-light-small.png` (plus `.log`).
