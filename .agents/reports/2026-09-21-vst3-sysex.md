# VST3 SysEx 与效果器/音源验收

本轮补齐主事件总线 SysEx，并按“效果器、音源能工作”的目标增加本机安装插件的联合验收。
工程快照仍为 Engine 1.7，二进制音频 stream 升至 11；control/独立 helper JSON 和 C ABI
版本不变。全部音频验证使用离线文件或模拟 sink，没有打开系统输出设备。

## 实现

- 完整 F0…F7 消息，内部 7-bit data；单条 2…4096 bytes，每个 process 段输入/输出各
  最多 16384 bytes，事件总数仍为 256。普通 MIDI、参数与音符共享事件预算。
- 40-byte 包头原 offset 36 变为 payloadBytes；kind 5 的固定记录保存 offset/length，
  payload 跟在 PCM/事件之后。拒绝旧 stream 1…10、越界、坏格式、非零保留位及超预算。
  配套 TS 契约、全部活动调用方和生成 schema 已迁移；不改写旧恢复数据。
- Rust Event 保持小型 Copy 记录，payload 放入预分配 arena；端口提交/接收及 ScheduledPort
  短段拼包不分配、不释放。后者支持 SysEx 输入，仍拒绝 MIDI 输出捕获。
- 图路由支持复制、扇入、扇出和精确 sample offset；扇入超预算先拒绝，不部分修改。
  SysEx 使旧 authored 参数缓存失效，避免插件改参后丢掉同值显式控制。
- helper 复制厂商 outputData 后再传输，不持有跨调用的厂商指针。reset/restart/故障清空
  旧事件与 payload；未路由输出继续忽略，开启捕获后的非法输出终止插件。
- 独立 WAV API 接受 `type: "sysEx"`；逐块预算在加载插件和创建输出文件前验证。
  新增测试插件包含 SysEx 发射、透传、接收音源及畸形/超预算输出。
- 新增模块、测试与集成脚本保持单一职责；事件/codec 等源文件均小于 300 格式化行。

## 检查

- `pnpm test`：125 suites / 500 tests 通过。
- `cargo test --workspace`：92 suites / 661 passed、3 ignored、0 failed；忽略项为已有设置。
- `cargo test -p oxitone-vst3-host --features host,stream --locked`：74 passed。
  满载 SysEx 端口和短段拼包验证 allocation/free 均为零，覆盖预算失败不改变已接受数据。
- `pnpm build`、Preview debug bundle、`pnpm build:wasm` 与 schema 生成完成。
- `pnpm format:check`、`pnpm lint`、`pnpm typecheck`、`cargo fmt --all --check`
  以及原生 fixture 格式检查通过。
- 原生 MIDI 集成包含每包 16 KiB 的 400 次 SysEx echo，验证 0/13/63/127 帧位置、厂商
  指针失效后的字节、reset、禁用捕获及三种非法输出。MIDI-only 透传到音源、mute、扇出与
  保存恢复各比较 48000 样本；最大误差分别为 0、0、1.401298464324817e-45、0。
  独立 WAV 输入比较 512 样本，误差零；超预算输入没有发布 WAV。
- macOS arm64/x64 CI 的 MIDI 步骤已包含 SysEx；本轮没有触发远端 CI。

## 性能

全仓测试与构建完成后独立运行基准及原生回归。Apple M4、Darwin 27 arm64、Rust 1.98.1 /
LLVM 22.1.8，48 kHz、128 frames。SysEx port 往返 p95/p99 为 0.313167/0.316250 ms。
SysEx 图模拟播放 243 blocks，零欠载、deadline miss、NaN、queue drop 或插件 fault；后台
块时间 p95/p99 直方图桶为 1.048576 ms。设备 callback p95/p99 均未测，不能用 IPC/后台
数据代替硬件 callback 验收。

Playlist 使用 1 秒预热、2 秒测量、20 samples；初次 32/1024 placements 估算为
109.72/121.31 µs。Criterion 对前次本地均值分别报告 -10.21%/+8.89%，保留回退结果。
因 1024 均值出现回退，单独复测一次，估算为 111.76/116.46 µs；相对初次分别为
+3.67%/-10.24%。两次 2048-block DSP profile 如下：

| placements | 初次 p95/p99 µs   | 复测 p95/p99 µs   |
| ---------- | ----------------- | ----------------- |
| 32         | 122.791 / 127.333 | 123.417 / 128.625 |
| 1024       | 131.042 / 136.792 | 134.209 / 139.958 |

两次数据均保留；相邻本地均值存在波动，不能选取较好的一次作为发布基线结论。
历史发布基线的同源性仍未确认，本记录不宣称发布性能门禁已通过。
