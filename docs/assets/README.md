# Oxitone brand assets

`oxitone-logo.webp` is the selected repository logo. It was generated with the official Replicate
`openai/gpt-image-2` model (the API currently exposes this model and `gpt-image-2.5-flare`, but no bare
`gpt-image-2.5` identifier). The mark uses three rounded mixer channels around a central play aperture, with a single
electric-blue accent. Its restrained geometry and generous negative space are designed for DAW and GitHub icon sizes.

The design intentionally uses a dark rounded-square field and a small set of flat colors so it remains legible as a
DAW or GitHub app icon at small sizes.

`oxitone-logo.svg`, `concept-signal-orbit.svg`, `gpt2-a.webp`, `logo-code-low/`, `logo-code-medium/`, `logo-daw-a/` and `logo-daw-b/` retain Replicate
exploration renders for provenance. The prediction manifests record model inputs and output URLs; no credentials are
stored.
