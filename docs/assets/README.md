# Oxitone brand assets

`oxitone-logo.webp` is the selected repository logo. It was generated with Replicate's
`openai/gpt-image-2.5-flare` model at medium quality using an opaque 1:1 canvas. The final prompt describes a DAW
app icon: a continuous cyan waveform becoming a playhead and an O-shaped mark, with a violet beat marker.

The design intentionally uses a dark rounded-square field and a small set of flat colors so it remains legible as a
DAW or GitHub app icon at small sizes.

`logo-code-low/`, `logo-code-medium/`, `logo-daw-a/` and `logo-daw-b/` retain exploration renders for provenance.
The prediction manifests record model inputs and output URLs; no credentials are stored.
