# Oxitone brand assets

`oxitone-logo.svg` is the selected repository logo. It is a hand-drawn, scalable vector mark: a timeline loop forms
the O, a continuous oscillator waveform crosses it, and a small playhead and beat ticks establish the DAW context.
The dark navy field and cyan/violet accents are defined as reusable SVG gradients and remain crisp at any size.

The design intentionally uses a dark rounded-square field and a small set of flat colors so it remains legible as a
DAW or GitHub app icon at small sizes.

`oxitone-logo.webp`, `logo-code-low/`, `logo-code-medium/`, `logo-daw-a/` and `logo-daw-b/` retain Replicate
exploration renders for provenance. The prediction manifests record model inputs and output URLs; no credentials are
stored.
