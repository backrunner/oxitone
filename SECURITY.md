# Security policy

Oxitone is pre-1.0 software. Please do not disclose a suspected vulnerability in a public issue when it could expose
users, project files or native audio hosts. Send a private report through the
[GitHub security advisory form](https://github.com/backrunner/oxitone/security/advisories/new) with the affected
commit, reproduction steps and impact. We will acknowledge reports as soon as practical and coordinate a fix and
disclosure timeline.

The development test server and native preview should be treated as local, trusted processes. Do not expose them to
untrusted networks. Keep dependencies updated and review the open Dependabot alerts on the repository's Security tab.
